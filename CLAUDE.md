## LaTeX
- Build: `latexmk` (pdflatex + biber via .latexmkrc). A build is clean
  only if `grep -E '^!' main.log` returns nothing. Run `latexmk -C` first
  if citations behave oddly after a .bib change.
- Edits to .tex are sentinel-gated splices between BEGIN/END markers, done
  by a Python patch script in scripts/ that: asserts its anchors match
  exactly once (whitespace-insensitive), writes a .bak, adds an
  `% EDITED <date>` header, and refuses to run twice.
- Unicode is allowed in .tex and .md where it belongs to a name, title or
  quoted source (Godel, Goettingen, Caslav all need it). Typography is not
  a name: use the LaTeX idioms, --- and -- for dashes, `` and '' and ' for
  quotes, \S for the section sign, never the literal characters. Ligature
  codepoints (U+FB01 fi, U+FB03 ffi) are PDF copy-paste damage and are
  always wrong. British English. Paragraphs, not bullets, in paper prose.
  Citations via \autocite.
- Show the diff and the compile result; commit only after John approves.

## Bibliography
- references.bib is generated by Better BibTeX from the Zotero collection.
  Never edit it by hand. Missing key => it's a Zotero problem, not a .bib one.
- New references: write a dated BibLaTeX batch to bib/, as .bib and never as
  .ris (bib/README.md has the full recipe). RIS has no citation-key field, so Zotero drops the ID and BBT invents
  a formula key; BBT's own importer keeps the entry key of a .bib and pins it
  (preference importCitationKey, on by default). The entry key IS the citation
  key, author+year+keyword. Import with File > Import, choose the .bib, and
  check the Citation Key column shows your key before exporting. DOI only when
  it is deterministic. Native Unicode is fine in .bib; BBT emits it for author
  names and it must not be mangled back. Brace any word whose capitals must
  survive --- BBT sentence-cases titles on import.
- Any citation you cannot verify against a source you actually read is
  marked VERIFY-CITE in the text and listed in your summary.
- knowledge/publications/ is exempt from all of the above. Those .bib files
  belong to finished work and keep their own keys; never regenerate them,
  reconcile them with Zotero, or cite from them.
